# マイナーOSデータベース

同人誌「Operating System Maniacs」シリーズ(Far Northern Other World)の作者が、本を作るときの下調べとしてまとめている、マイナーなOSの一覧です。あわせて、シリーズの既刊でどのOSを扱ったかの一覧も載せています。

- **データの時点: 2026年10月20日**(既刊の一覧は2026年10月28日、既刊から足したOSは2026年11月15日)
- 件数: マイナーOS 338件 / 既刊で扱ったOS 207行

各OSの状態や最新版は調べた時点のものです。その後に新しい版が出ていたり、開発が止まっていたりすることがあります。使うときは、各OSの公式サイトで確かめてください。

## ファイル

| ファイル | 内容 |
|----------|------|
| [`minor-os-list.csv`](minor-os-list.csv) | マイナーOSの一覧(338件)。状態・最新版と、本シリーズで扱ったかどうか |
| [`osm-articles.csv`](osm-articles.csv) | 本シリーズの既刊で扱ったOSの一覧(207行)。号・記事名など |

どちらもUTF-8(BOM付き)のCSVです。GitHub上では表として表示され、検索もできます。Excelでもそのまま開けます。

## 対象

- Windows・Linuxディストリビューション・BSD系ディストリビューションは除いています
- 判断がつかないものは入れています(分類に「判断保留で収録」と書いたもの)
- 商用のマイナーOS(QNX、VxWorks、OpenVMS、ArcaOS、MorphOS、AmigaOSなど)も入れています。AIX・HP-UX・z/OS・IBM iなどの大手の商用Unix・メインフレームOSは入れていません
- 「AIエージェントOS」と名乗るアプリケーションは、OSではないので除いています
- **例外**: 本シリーズの既刊で扱ったOSは、上の対象から外れるもの(Linux・BSDのディストリビューション、大手の商用OSなど)でも載せています。その場合は「注記」の列に理由を書いています。ただし、ハードウェアや、OSではないソフトウェア(OpenStackなど)は載せていません
- 調査はGitHubなどの検索から候補を集めたので、すでにサイトがなくなった古いOSは拾えていません。既刊で扱った古いOSは、既刊の一覧から足しています(No 210以降)

## 列の意味(minor-os-list.csv)

| 列 | 内容 |
|----|------|
| 分類 | OSの種類(デスクトップ、マイクロカーネル、RTOS、Plan 9系など)。商用のOS(販売が終わったものを含む)は、末尾に「(商用)」と付けています |
| 状態 | 下の「状態の決め方」を参照 |
| 最新版 / 最新版の日付 | GitHubのReleaseがあればその版。なければ、コミット日がいちばん新しいタグ。公式サイトで確かめたものは公式サイトの版を優先しています。日付の後ろの「(タグ)」はタグから取ったもの、「(未確認)」は日付が見つからなかったもの |
| 公式サイト・リポジトリ | 公式サイト。ないものは主なリポジトリ |
| 本シリーズでの扱い | 下の「本シリーズでの扱い」を参照 |
| 扱った号・関係 | 扱った号(例: `2nd 10号`)。「系統は扱い済み」のものは、どの系統を扱ったか |
| 注記 | 上の「対象」の例外として載せたものの理由など(既刊から足したOSだけに付けています) |

### 状態の決め方

| 状態 | 意味 |
|------|------|
| 活発 | GitHubの最終更新(push)が半年以内 |
| 更新少なめ | 最終更新が2年以内 |
| 停滞 | 最終更新がそれより前 |
| 商用(継続) | 商用で、販売・提供が続いているもの |
| 開発終了 | 開発・販売が終わったことがはっきりしているもの |
| 未確認 | 今の状況を確かめられなかったもの |
| アーカイブ済み | リポジトリがアーカイブ(読み取り専用)になっているもの |
| 終了(作者死去) | 作者が亡くなり、開発が終わったもの |

GitHubにないOSは、公式サイトのニュースなどから手で付けています。既刊から足したOSのうち、サイトがなくなったホビーOSは「停滞」にしています。

### 本シリーズでの扱い

| 値 | 意味 |
|----|------|
| 扱い済み | 同じOSを既刊で扱った(版違いを含む) |
| 系統は扱い済み | 派生・後継・同じ系統の別のOSを扱った(例: OmniOSは、同じillumos系のOpenIndianaを扱い済み) |
| 未扱い | まだ扱っていない |

## 列の意味(osm-articles.csv)

| 列 | 内容 |
|----|------|
| シーズン / 号 / 発行 | 1st(無印)・2nd・3rd の各号と、発行日・イベント |
| 扱い | 単独記事 / 特集の一項目(特集の中の1本) / 駆け足レビュー(「マイナーOS駆け足レビュー」の中の1項目) / コレクション紹介(手持ちのパッケージ・メディアの紹介で、動かしてはいない) / 言及・回想 |
| 執筆 | 寄稿の記事は「(寄稿)」を付けています |

同じOSが別の号に出てくる場合は、行を分けています。総集編(2018年版・第1弾・第2弾)は、元の号と重なるので入れていません。

## 調べ方

一覧は、作者が Claude Code(AnthropicのAIエージェント)に調べてもらった結果を、作者が確認してまとめたものです。

- **候補探し**: GitHubのトピック(operating-system、hobby-os、osdev、kernel、rtos、microkernel、unikernel など)と説明文の検索、awesome-os の一覧、Codeberg・GitLab.com の検索、Lobsters の osdev タグなど
- **状態・最新版**: GitHub API で最終更新日・Release・タグを取得。GitHub以外のOSは公式サイトのダウンロードページやニュースで確認
- **既刊での扱い**: 既刊の原稿・PDFと突き合わせ

ボット確認の画面(Cloudflareなど)や403を返すサイトは、アクセス制限なので回避せず、ミラーや検索結果で代わりに確かめています。そのため、一部のOSは版や日付が確かめきれていません。
